## Screen Recording

A screen recording demonstrating the complete student flow is referenced as:
- **`complete-flow-demo.mp4`** (or `.webm`)

### Recording Script:
1. Open http://localhost:5173
2. Register a new student account
3. Browse the menu and filter by Lunch
4. Click on "Chicken Biryani" to view details
5. Add it to cart
6. Go to cart, click "Select Pickup Time"
7. Choose the AI-recommended slot
8. Complete checkout
9. Show the Order Confirmation with digital token
10. Navigate to Order Tracking — show live status
11. Switch to admin view (new tab)
12. Login as admin@canteen.com
13. Accept the order → Start Prep → Mark Ready
14. Switch back to student view — show READY status
15. Show the Kitchen Queue and Analytics pages
