# User Testing Plan
## AI-Smart Ordering System

**Testing Period:** 16–18 September 2026  
**Method:** Moderated usability testing with think-aloud protocol  
**Testers:** 3 individuals representing primary and secondary user personas

---

## Testing Approach

Each tester was given a printed task sheet and asked to work through the tasks independently while thinking aloud. The researcher observed silently, taking notes on:
- Where the tester hesitated
- Where errors occurred
- What the tester said spontaneously
- How long each task took
- Whether the task was completed successfully

Post-task debrief questions were asked after all tasks were complete.

**Note:** Tester last names and identifying personal details are not included. Role labels protect privacy.

---

## Task Sets

### Student Task Set (Testers 1 and 2)
```
Task  1: Create a new account
Task  2: Browse the full menu
Task  3: Find and add a specific item (Chicken Biryani) to cart
Task  4: Add a second item from a different category
Task  5: View the cart and verify items
Task  6: Navigate to Smart Pickup Time and select a slot
Task  7: Complete checkout and place the order
Task  8: Note your order token number
Task  9: Navigate to Order Tracking using the token
Task 10: View your Order History
Task 11: Try the AI Recommendations feature
Task 12: View your Profile page
```

### Admin Task Set (Tester 3)
```
Task  1: Login as admin
Task  2: View the Admin Dashboard — find today's order count
Task  3: Navigate to Orders — find a pending order
Task  4: Accept the pending order
Task  5: Move the order to Preparing
Task  6: Mark the order as Ready
Task  7: Navigate to Kitchen Queue
Task  8: Add a new menu item (your choice of dish)
Task  9: Toggle an existing item to unavailable
Task 10: View Analytics
```

---

## Success Criteria

| Result | Meaning |
|--------|---------|
| ✅ Success | Task completed without assistance |
| ⚠️ Partial | Task completed but with hesitation, confusion, or multiple attempts |
| ❌ Failure | Task could not be completed |

---

## Post-Task Questions (All Testers)
1. What was the most useful feature you used?
2. What confused you most?
3. Did anything not work as you expected?
4. How would you rate the overall experience (1–10)?
5. Would you use this system if it were available at your canteen?
