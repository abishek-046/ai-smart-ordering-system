# User Journey Map
## College Canteen Experience — Current State vs. Future State

**Project:** AI-Smart Ordering System  
**Primary Persona:** College Student with tight academic schedule  
**Mapping date:** 14 September 2026

---

## Persona: Priya — The Time-Constrained Student

| Attribute | Detail |
|-----------|--------|
| Name | Priya (representative persona) |
| Year | 2nd year, Computer Science Engineering |
| Schedule | Back-to-back classes, 15-minute lunch break (12:45–1:00 PM) |
| Device | Smartphone (uses Swiggy, Zomato) |
| Goal | Eat a proper meal without being late to class |
| Fear | Skipping lunch again because of the queue |

---

## Current State Journey (Without System)

| Stage | Actions | Thoughts | Feelings | Pain Points | Opportunity |
|-------|---------|---------|---------|------------|-------------|
| **1. Decision** (12:44 PM) | Class ends. Considers whether to go to canteen. | "Is it worth the risk? Will the queue be too long?" | Anxious, uncertain | No way to check queue remotely | Show live queue status before leaving class |
| **2. Travel** (12:45–12:48 PM) | Walks 3–4 minutes to canteen | "Hope it's not too crowded today" | Hopeful, slightly rushed | Travel time eats into 15-min break | Pre-ordering removes need for urgent physical presence |
| **3. Queue entry** (12:48 PM) | Joins queue of 20+ students | "This is going to take forever" | Frustrated, calculating remaining time | 8–15 min wait ahead with no information | Eliminate queue with token pickup system |
| **4. Queue wait** (12:48–1:00 PM) | Stands in queue, checking phone | "Am I going to make it to class?" | Stressed, counting minutes | No progress information, no estimate given | Real-time position updates |
| **5. Counter reach** (1:00 PM) | Reaches counter, asks for Chicken Biryani | "Please let it be available" | Tense | Told item is sold out — after 12 min of waiting | Check availability at order time, before commitment |
| **6. Fallback choice** (1:01 PM) | Orders 2nd-choice item (Dal Rice) | "Not what I wanted. Not worth the wait." | Disappointed, resigned | No advance availability info existed | Show real-time availability before ordering |
| **7. Pickup wait** (1:01–1:08 PM) | Waits additional 7 minutes for food | "I'm going to be late" | Stressed, watching clock | No preparation time estimate given | AI-predicted pickup time eliminates this uncertainty |
| **8. Rushed eating** (1:08–1:10 PM) | Eats quickly, food lukewarm | "I have 2 minutes" | Rushed, unsatisfied | Food quality diminished, no time to eat properly | Correct pickup time means food is fresh when collected |
| **9. Late to class** (1:12 PM) | Arrives 5 minutes after class starts | "This happens every day. I'm exhausted." | Defeated, embarrassed | Repeated pattern, no solution visible | This entire journey is replaced by pre-ordering |

**Emotional Curve:** Anxious → Hopeful → Frustrated → Stressed → Disappointed → Stressed → Rushed → Defeated

**Peak Pain Point:** Stage 5 — Discovering sold-out item after full wait time invested.

---

## Future State Journey (With AI-Smart Ordering System)

| Stage | Actions | Thoughts | Feelings | Experience |
|-------|---------|---------|---------|-----------|
| **1. Pre-order** (12:30 PM — during previous class) | Opens website on phone, browses menu, sees Chicken Biryani is available, adds to cart | "Perfect, it shows it's available and 130 rupees." | Calm, in control | Browsing real menu with real availability |
| **2. AI Pickup Time** (12:31 PM) | Taps "Smart Pickup Time" — sees AI recommends 12:58 PM (low queue slot) | "12:58 is perfect — I can go right after class ends" | Confident, planned | AI predicts best slot based on live kitchen load |
| **3. Order confirmation** (12:32 PM) | Places order, receives token ORD-0915-4821 | "Done. I can relax for the rest of class." | Relieved, focused | Digital token in 60 seconds — no queue needed |
| **4. Class ends** (12:44 PM) | Sees order status: "Preparing" | "It's already being made" | Satisfied | Live status via 15-second polling — no uncertainty |
| **5. Walk to canteen** (12:44–12:48 PM) | Walks at normal pace, no rushing | "By the time I get there it'll be ready" | Relaxed | Travel time used productively |
| **6. Collection** (12:48 PM) | Approaches dedicated pickup counter, shows token, collects food | "Zero wait. This is amazing." | Delighted | No queue, no verbal exchange, no errors |
| **7. Eating** (12:48–12:58 PM) | Eats properly with 10 minutes to spare | "I can actually sit down and eat." | Satisfied, energised | Full meal, seated, before class |
| **8. Class** (1:00 PM) | Arrives on time | "That actually worked perfectly." | Confident, ready | Zero academic impact |

**Emotional Curve:** Calm → Confident → Relieved → Satisfied → Relaxed → Delighted → Satisfied → Confident

**Key Transformation:** 45-minute stressed, uncertain, disappointing experience → 18-minute controlled, predictable, satisfying experience.

## Journey Comparison

| Dimension | Current State | Future State |
|-----------|--------------|-------------|
| Time spent on food | 25–30 min (queue + wait + rushed eating) | 12–15 min (order 2 min + walk + collect) |
| Information at decision point | None | Full menu, availability, AI pickup time |
| Certainty of getting desired food | Unknown until counter | Confirmed at order time |
| Queue time | 8–15 min | 0 min (dedicated pickup counter) |
| Academic impact | Late to class 2–3x/week | No impact |
| Emotional state throughout | Anxious → Defeated | Calm → Satisfied |
| Staff workload at peak | Overwhelmed, errors | Manageable, advance-planned |
| Food waste | ~15% daily | Reduced (demand-matched production) |

## Opportunity Zones (Where the System Intervenes)

```
DECISION POINT ──────────────────────────────────────────────────
  Current: No information → anxious guess
  System:  Live availability + AI slot recommendation → confident planning

QUEUE ELIMINATION ───────────────────────────────────────────────
  Current: Physical queue, 8–15 min, no movement information
  System:  No queue — token holder goes directly to pickup

AVAILABILITY VERIFICATION ───────────────────────────────────────
  Current: Discover at counter after full wait
  System:  Verified at order time, blocked from ordering unavailable items

PREPARATION VISIBILITY ──────────────────────────────────────────
  Current: "Kondey" (Coming) — unknown wait at pickup
  System:  AI-predicted prep time + live status tracking

KITCHEN COORDINATION ────────────────────────────────────────────
  Current: Staff guessing quantity, verbal relay, batching impossible
  System:  Advance orders → kitchen prepares correct quantities in batches
```
